# LogicLens

An interactive propositional-logic playground (Hebrew UI), built with Streamlit.

Enter a logical formula and get:

- A full truth table with sub-expression breakdown and highlighted results
- A Venn-diagram visualization of the formula over its variables

Supports conjunction, disjunction, negation, implication and equivalence, with an on-screen keyboard for logic symbols.

## Run

```sh
pip install -r requirements.txt
streamlit run app.py
```
